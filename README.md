# Data Cleaning & Preprocessing — Internship Applications

## Project Overview

This project demonstrates the cleaning and preprocessing of internship application data using Python and Pandas.

## Objectives

* Identify missing values
* Detect and remove duplicate records
* Identify and handle outliers
* Standardize categorical data
* Structure the dataset for further analysis
* Export the cleaned dataset

## Tools Used

* Python
* Pandas
* NumPy
* Jupyter Notebook

## Data Cleaning Steps

1. Loaded the internship application dataset.
2. Checked the dataset structure and data types.
3. Identified missing values.
4. Handled missing numerical values.
5. Checked and removed duplicate records.
6. Standardized Gender and Department values.
7. Detected unrealistic age values.
8. Checked numerical data for outliers using the IQR method.
9. Exported the cleaned dataset as a CSV file.

## Files

* `Data_Cleaning_and_Preprocessing_Internship.ipynb` — Jupyter Notebook containing the complete Python workflow.
* `internship_applications_cleaned.csv` — Final cleaned dataset.

## Result

The final dataset is cleaned, standardized, and ready for further analysis and visualization.
